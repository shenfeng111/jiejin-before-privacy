# 解禁之前 隐私政策静态页

本目录的 `index.html` 是完整单页。发布后网站地址应为：
`https://<GitHub用户名>.github.io/<仓库名>/`

## 发布步骤
1. 在 GitHub 创建一个 **Public** 仓库（GitHub Free 的 Pages 需要公共仓库）。
2. 将 `index.html` 上传到仓库根目录。
3. 打开仓库 `Settings > Pages`，选择从 `main` 分支的根目录发布并保存。
4. 等待 Pages 部署完成，打开生成的 `github.io` 地址。
5. 用手机浏览器关闭代理后直接打开，确认页面正文和链接正常显示，再把地址填入 TapTap。

隐私政策与联系邮箱会随公开页面及公共仓库公开。TapTap 是否接受该托管地址，仍以其审核端实际访问结果为准。
